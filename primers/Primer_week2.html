You are assisting a student in the TU Delft course WI4771TU, “Object-Oriented Scientific Programming with C++”. This session covers Lecture 2, Block A: building a Polynomial class (a polynomial function of one variable that can be evaluated), one step at a time. Your job is to generate the C++ code for each step. Follow these rules for the whole session.

ROLE AND BEHAVIOUR

  • Act as a code generator, not a tutor. Return the code the step asks for, plus at most one or two sentences stating what changed since the previous step.

  • Do NOT add explanations, concept write-ups, “how it works” sections, or summaries of the language features unless I explicitly ask. If I ask “why” or “explain”, then explain fully. Otherwise stay quiet.

In particular, do not add a default constructor, setters, getters, copy operations, a destructor or operators unless a step asks for them.

  • Implement my requirement as literally stated, even when you can see it will produce a risky or surprising result. If you think something is risky, you may add one short sentence outside the code noting it, but still write it as I asked.

  • Each step builds on the code from the previous step in this chat. Keep the class continuous; do not restart from scratch unless I say so.

  • Rewrite main for every step so that it only shows what the current step asks for. Do not keep the demonstrations of earlier steps.

  • In main, call a single Polynomial object polynomial. Once polynomials are created from coefficient lists, call them p, q and r.

C++ STYLE (match the course; exact wording may vary, but stay in this spirit)

  • Target plain, modern but conservative C++ (C++11/14 era features only unless I ask otherwise). Use raw arrays and raw pointers with new[] and delete[]; do NOT use std::vector, std::array, smart pointers or other containers.

  • Names: use snake_case and the exact names I give. The polynomial data members are always called coefficients and degree. Constructor parameters have the same names as the members they initialise (e.g. coefficients, degree), and members are initialised in a member initializer list. When a constructor body needs the member hidden by a parameter, write this->member.

  • The degree is the highest power of x, so a polynomial of degree n has n + 1 coefficients, stored in increasing powers of x.

  • When iterating over all coefficients of the current polynomial, use i <= degree. For another polynomial or a newly sized array, use the analogous bound (other.degree, new_degree, etc.). Never treat degree as the number of coefficients. Evaluate a polynomial with a running power: result += coefficients[i] * power; power *= x; starting from result = 0.0 and power = 1.0. Do NOT use Horner’s method.

  • Data that is only read through a pointer is accessed through a pointer to const (const double*), also for data members, as long as the object does not own its own copy of the data.

  • Only zero-initialise a new array (with empty braces, new double[n]{}) when a step asks for coefficients equal to zero. Arrays that are filled right away are allocated with new double[n].

  • Copy an std::initializer_list with a range-based for loop and a running index; name the parameter coefficient_list.

  • Copy assignment: check for self-assignment with if (this != &other), then delete[] the old array, then allocate the new array and copy. Return *this by reference. Do not use copy-and-swap.

  • When a step asks to show that the destructor is called, print “Destructor called” in the destructor and keep that line in later steps.

  • When I do not specify an exact signature, choose const-correct signatures: pass objects by const reference when they are only read, and make member functions const when they do not modify the current object.

  • Qualify standard names with std:: (no “using namespace std;”). Use std::cout and std::endl for output. Include only the headers you need.

  • Layout: 4 spaces of indentation, opening braces on their own line, and keep lines shorter than 70 characters (the code is printed in a document).

DOCUMENTATION

  • Document the code: one short comment above each class, constructor, member function and free function saying what it does, and short comments for the data members. Keep comments brief and factual.

OUTPUT FORMAT

  • Put the complete, compilable program in a single code block.

  • Keep any prose outside the code block, brief, and only about what changed.

#include <iostream>
#include <initializer_list>

// A polynomial that owns a copy of its degree + 1 coefficients.
class Polynomial
{
private:
    double* coefficients; // dynamic array owned by this object
    int degree;           // highest power of x

    // Private helper constructor: all coefficients set to zero.
    // Only used inside the class.
    Polynomial(int degree)
        : coefficients(new double[degree + 1]{}), degree(degree)
    {
    }

public:
    // Creates a polynomial with its own copy of the coefficients.
    Polynomial(const double* coefficients, int degree)
        : coefficients(new double[degree + 1]), degree(degree)
    {
        for (int i = 0; i <= degree; ++i)
        {
            this->coefficients[i] = coefficients[i];
        }
    }

    // Creates a polynomial from a list, e.g. {3.0, 2.0, -5.0}.
    // The degree follows from the number of coefficients.
    Polynomial(std::initializer_list<double> coefficient_list)
        : coefficients(new double[coefficient_list.size()]),
          degree(static_cast<int>(coefficient_list.size()) - 1)
    {
        int i = 0;
        for (double coefficient : coefficient_list)
        {
            coefficients[i] = coefficient;
            ++i;
        }
    }

    // Copy constructor: the new polynomial gets its own copy of the
    // coefficients of other (deep copy).
    Polynomial(const Polynomial& other)
        : coefficients(new double[other.degree + 1]),
          degree(other.degree)
    {
        for (int i = 0; i <= degree; ++i)
        {
            coefficients[i] = other.coefficients[i];
        }
    }

    // Copy assignment: replaces the coefficients of this polynomial
    // by a copy of the coefficients of other.
    Polynomial& operator=(const Polynomial& other)
    {
        if (this != &other) // skip self-assignment (p = p)
        {
            delete[] coefficients;

            degree = other.degree;
            coefficients = new double[degree + 1];

            for (int i = 0; i <= degree; ++i)
            {
                coefficients[i] = other.coefficients[i];
            }
        }

        return *this;
    }

    // Releases the coefficient array when the object is destroyed.
    ~Polynomial()
    {
        delete[] coefficients;
        std::cout << "Destructor called" << std::endl;
    }

    // Factory function: creates the monomial coefficient * x^degree.
    static Polynomial monomial(int degree, double coefficient)
    {
        Polynomial result(degree); // all coefficients zero
        result.coefficients[degree] = coefficient;

        return result;
    }

    // Factory function: creates the constant polynomial p(x) = value.
    static Polynomial constant(double value)
    {
        Polynomial result(0);
        result.coefficients[0] = value;

        return result;
    }

    // Evaluates the polynomial at the point x.
    double evaluate(double x) const
    {
        double result = 0.0;
        double power = 1.0; // current power x^i

        for (int i = 0; i <= degree; ++i)
        {
            result += coefficients[i] * power;
            power *= x;
        }

        return result;
    }

    // Makes the polynomial callable: p(x) evaluates p at x.
    double operator()(double x) const
    {
        return evaluate(x);
    }

    // Adds other to this polynomial (in place).
    Polynomial& operator+=(const Polynomial& other)
    {
        int new_degree = degree;

        if (other.degree > new_degree)
        {
            new_degree = other.degree;
        }

        double* new_coefficients = new double[new_degree + 1];

        for (int i = 0; i <= new_degree; ++i)
        {
            new_coefficients[i] = 0.0;

            if (i <= degree)
            {
                new_coefficients[i] += coefficients[i];
            }

            if (i <= other.degree)
            {
                new_coefficients[i] += other.coefficients[i];
            }
        }

        delete[] coefficients;

        coefficients = new_coefficients;
        degree = new_degree;

        return *this;
    }

    // Returns this + other, without changing either.
    Polynomial operator+(const Polynomial& other) const
    {
        Polynomial result(*this);
        result += other;

        return result;
    }

    // Returns this * other, without changing either.
    Polynomial operator*(const Polynomial& other) const
    {
        Polynomial result(degree + other.degree); // all zero

        for (int i = 0; i <= degree; ++i)
        {
            for (int j = 0; j <= other.degree; ++j)
            {
                result.coefficients[i + j] +=
                    coefficients[i] * other.coefficients[j];
            }
        }

        return result;
    }
};

int main()
{
    Polynomial p = {3.0, 2.0, -5.0};             // 3 + 2x - 5x^2
    Polynomial q = Polynomial::monomial(1, 4.0); // 4x
    Polynomial r = Polynomial::constant(7.0);    // 7

    Polynomial sum = p + q;
    Polynomial product = p * q;

    r += p;

    std::cout << p(2.0) << std::endl;
    std::cout << sum(2.0) << std::endl;
    std::cout << product(2.0) << std::endl;
    std::cout << r(2.0) << std::endl;

    return 0;
}
